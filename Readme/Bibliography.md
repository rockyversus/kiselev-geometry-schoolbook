# Ссылки и источники

## Ссылки внутри книги

Связывайте ссылки с метками LaTeX. Для рисунков используйте `\ref{...}`, для страниц — `\pageref{...}`. Ссылки на параграфы и пункты можно делать кликабельными целиком через `\hyperref[...]{...}`. Например, в главе V:

```tex
\hyperref[para:perpendicular-planes-criterion]{см.~§~\ref*{para:perpendicular-planes-criterion}}
```

Команда `\ref*` выводит номер без дополнительной ссылки внутри уже кликабельного текста.

## Ссылки на издание 1914 года

В главах II–V ссылки на планиметрию ведут на скан Киселёва. Команда `\kiselevPlanimetryPage` принимает номер страницы скана и текст ссылки. В этом скане номер на 11 больше печатного. Например, пункт 2 § 59 напечатан на странице 42 и находится на странице 53 скана.

```tex
\kiselevPlanimetryPage{53}{см.~Планиметрия, §~59, пункт~2}
```

[Открыть страницу 53 скана](<https://commons.wikimedia.org/wiki/File:А._П._Киселёв._Элементарная_геометрия_(1914).djvu?page=53>)

## Библиография

Базы `.bib` находятся в `biblio/`. Если в книгу добавляется отдельный библиографический источник, внесите его в `biblio/external.bib` и сослитесь на ключ записи через `\cite{...}`. Сборка обрабатывает эти записи с помощью Biber. [База внешних источников](../biblio/external.bib) · [Сборка](Installation.md)

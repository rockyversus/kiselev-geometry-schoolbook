# Как предложить правку

Если заметили ошибку, укажите параграф или рисунок, страницу PDF и спорное место. Для ошибок переноса приложите печатный номер страницы оригинала или ссылку на скан. Так правку можно быстро сверить с источником. [Открыть задачу на GitHub](https://github.com/rockyversus/kiselev-geometry-schoolbook/issues/new/choose)

## Правка исходников

1. Сделайте правку в отдельной ветке. Текст глав находится в `Book/part1.tex`–`Book/part5.tex`, рисунки — в `Book/images/`.
2. Сверьте исправление с изданием 1914 года. Сохраняйте авторские термины, обозначения и ход доказательства. Расхождения в печатном источнике поясняйте в сноске с пометкой «Прим. ред.».
3. Соберите книгу и проверьте изменённые страницы, связанные рисунки и ссылки. [Команда сборки](Installation.md)
4. В запросе на слияние укажите, что исправлено и по каким страницам оригинала это проверено.

## Выпуск PDF

1. Запустите `make release` через GNU Make. В Windows команда может называться `gmake release`. Цель собирает книгу через pdfLaTeX, обновляет `kiselev-stereometry-book-1.pdf` в корне и подготавливает этот PDF к коммиту.
2. Откройте подготовленный PDF и проверьте изменённые страницы, оглавление, рисунки и ссылки. Обновите ссылки на выпуск и скачивание в README под новый тег. Сохраните PDF, исходники и README одним коммитом и поставьте на него тег выпуска.
3. На GitHub создайте выпуск с этим тегом. Укажите в названии раздел, номер и название книги. Прикрепите `kiselev-stereometry-book-1.pdf` из коммита, чтобы просмотр в репозитории и скачивание из Releases давали один и тот же файл. [Управление релизами на GitHub](https://docs.github.com/en/repositories/releasing-projects-on-github/managing-releases-in-a-repository)
4. Обновите прямую ссылку в About и проверьте просмотр и скачивание PDF без входа на GitHub.

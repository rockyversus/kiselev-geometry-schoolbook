# Как предложить правку

Если заметили ошибку, укажите параграф или рисунок, страницу PDF и спорное место. Для ошибок переноса приложите печатный номер страницы оригинала или ссылку на скан. Так правку можно быстро сверить с источником. [Открыть задачу на GitHub](https://github.com/rockyversus/kiselev-geometry-schoolbook/issues/new)

## Правка исходников

1. Сделайте правку в отдельной ветке. Текст глав находится в `Book/part1.tex`–`Book/part5.tex`, рисунки — в `Book/images/`.
2. Сверьте исправление с изданием 1914 года. Сохраняйте авторские термины, обозначения и ход доказательства. Расхождения в печатном источнике поясняйте в сноске с пометкой «Прим. ред.».
3. Соберите книгу и проверьте изменённые страницы, связанные рисунки и ссылки. [Команда сборки](Installation.md)
4. В запросе на слияние укажите, что исправлено и по каким страницам оригинала это проверено.

## Выпуск PDF

Для выпуска книги приложите проверенный PDF к релизу на GitHub. Укажите в названии раздел, номер книги и её название. После публикации добавьте ссылку на выпуск в основной README. [Управление релизами на GitHub](https://docs.github.com/en/repositories/releasing-projects-on-github/managing-releases-in-a-repository)

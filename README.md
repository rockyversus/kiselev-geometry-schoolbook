# Геометрия Киселёва

## Стереометрия. Книга I «Прямые и плоскости»

Бесплатное электронное издание «Элементарной геометрии» А. П. Киселёва по 23-му изданию 1914 года.

[Открыть PDF на GitHub](kiselev-stereometry-book-1.pdf) · [Скачать PDF](https://github.com/rockyversus/kiselev-geometry-schoolbook/releases/download/v1.0.1/kiselev-stereometry-book-1.pdf) · [Релиз v1.0.1](https://github.com/rockyversus/kiselev-geometry-schoolbook/releases/tag/v1.0.1) · [Скан издания 1914 года](<https://commons.wikimedia.org/wiki/File:А._П._Киселёв._Элементарная_геометрия_(1914).djvu>)

В книгу вошли введение и пять глав Книги I, §§ 344–403. Все 52 рисунка Книги I, с 301-го по 352-й, восстановлены в TikZ.

1. Определение положения плоскости.
2. Перпендикуляр к плоскости и наклонные к ней.
3. Параллельные прямые и плоскости.
4. Двугранные углы.
5. Многогранные углы.

Орфография приведена к современной. Сохранены авторские термины, обозначения, нумерация и ход доказательств. Расхождения в печатном издании поясняются в редакторских сносках.

## Сборка

Понадобятся TeX Live 2026, `latexmk` и `biber`. Запустите следующую команду из корня проекта. Её же использует автоматическая сборка GitHub.

```sh
latexmk -norc -r latexmkrc -pdf -interaction=nonstopmode -halt-on-error dissertation.tex
```

Результат сборки — `dissertation.pdf`. [Установка и сборка](Readme/Installation.md)
